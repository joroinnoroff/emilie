# Emilie W. Lien

Minimalistic art portfolio and shop built for [emiliewlien.no](https://www.emiliewlien.no/).

Built with:

- Next.js
- TypeScript
- Sanity
- Tailwind CSS

The site showcases Emilie's paintings, projects, and available works through a simple editorial-style interface.

## Development

```bash
npm install
npm run dev
